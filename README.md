# Task Management Application – QA Testing

## Project Overview

This project contains the software testing documentation for a
Task Management Application.

The application provides:

- User Registration
- User Login
- Create Task
- View Task List
- Edit Task
- Delete Task
- Input Validation
- Error Handling

## Testing Approach

The testing approach includes:

- Positive testing
- Negative testing
- Edge-case testing
- Functional testing
- Input validation testing
- Error-handling testing

## Repository Structure

- test-cases/ – Detailed test cases
- bug-analysis/ – Potential bugs and risk areas
- documentation/ – Testing strategy and scenarios
- submission/ – Final assessment report

## Scope

Testing covers registration, login, task CRUD operations,
input validation and error handling.
